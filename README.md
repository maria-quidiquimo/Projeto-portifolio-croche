# Pontos de Encanto

Portfólio responsivo de crochê feito à mão, criado em HTML, CSS e JavaScript sem dependências de build.

## Como visualizar

Abra `index.html` no navegador. As fontes e fotografias são carregadas de serviços externos, então é necessária uma conexão com a internet para exibi-las.

## Personalização

- Troque os textos de apresentação e os nomes das peças em `index.html`.
- Substitua os endereços `images.unsplash.com` pelas fotos reais do ateliê.
- O contato principal e o link do rodapé levam ao Instagram [@pontosdeencanto.madu](https://www.instagram.com/pontosdeencanto.madu/).
- Ajuste as cores no bloco `:root` do CSS.
